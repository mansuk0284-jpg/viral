# Affiliate Cafe Insight

제휴카페는 **지역 생활 커뮤니티**다. 혼수 후기 건수로 재면 전부 0에 가깝게 나오지만,
다른 축으로 보면 경쟁·수요·활동성과 신호가 나온다. 이 스킬은 그 축으로 정리한다.

## Step 0. 대상 선정

`artifacts/affiliate-cafes.json`(84곳, clubId 포함)에서 고른다. 우선순위:

1. **부울경 14곳**(우리 권역) — 회원수순: 거사모 46.9만 / 울산 부동산 재테크 35.4만 /
   창원부동산이야기 21.4만 / 러브양산맘 18.8만 / 살통영 15.0만 / 진주아지매 13.3만 …
2. **백화점 소재 도시** — 창원·진주·김해·마산·부산·울산.
   (거제·통영·양산에는 백화점이 없다. 이 지역은 전자랜드·하이마트 경쟁 지역으로 따로 본다.)
3. 전국 대형 — 국민임대아파트 92만, 내집장만 아카데미 56.6만(둘 다 전국구·이사 수요 밀집)

한 번에 다 돌리지 않는다. **3~5곳씩 돌려 수확을 보고** 확장 여부를 정한다.

## Step 1. 수집

```
VIRAL_CLUBID=<clubId> VIRAL_CAFE_URL=<url> python scripts/naver_cafe_scraper.py \
  scrape --query "<아래 쿼리셋>" --pages 3 --max-articles 60 --no-read-body --headless
```

권장 쿼리셋(‘구매’ 금지 — 중고장터가 쏟아진다):
```
냉장고||세탁기||건조기||에어컨||TV||김치냉장고||가전 추천||가전 어디서||가전 견적||
전자랜드||하이마트||삼성스토어||디지털프라자||베스트샵||엘지 서비스
```

정확도가 필요하면 `--read-body`(느림, 로그인 세션 필요). 로그인은 사용자가 직접.

## Step 2. 5축 분류

수집한 글을 아래로 나눈다. 하나가 여러 축에 걸칠 수 있다.

| 축 | 판별 신호 | 뽑을 것 |
|---|---|---|
| **① 교체·이사 수요** | 고장·수명·이사·입주·급함 | 품목, 긴급도, 단품/패키지 |
| **② 경쟁 유통 노출** | 업체명 + 행사·세일·특별혜택·초대 | 유통사, 월, 소구문구 |
| **③ 구매처 문의** | "어디서", "잘해주는", "견적", "추천" | 지역, 시점, 댓글 추천 유통 |
| **④ 제휴 활동 반응** | 우리 원고 게시물 | 조회·댓글, 카페·문구별 효율 |
| **⑤ 중고 거래** | 삽니다·팝니다·중고 | 품목, 빈도 |

브랜드·품목 분류는 `scripts/brand_lexicon.py`와 `scripts/build_web_data.py`의
`ITEMS`/`RET_RE`/`dept_store_of`를 재사용한다. 여기서 새로 정의하지 않는다.

## Step 3. 인사이트 도출

기계적 집계로 끝내지 말고 **판매로 이어지는 해석**까지 간다.

- ②에서 **우리 노출이 경쟁사보다 적은 지역** → 제휴 원고 우선 배치 후보
- ③의 문의 글에 **경쟁 유통이 추천되고 있으면** → 그 카페는 방어가 필요한 곳
- ①의 교체 수요가 큰 품목 → 해당 지역 매장의 **단품·긴급 대응 재고**
- ⑤ 중고 거래가 많은 지역 → 보급형·전시품·구독 제안이 통할 세그먼트
- ④에서 반응 좋은 문구 → 다른 카페로 확산

## Step 4. 정직성 규칙 (필수)

- **표본 수를 먼저 쓴다.** 적으면 적다고 쓴다. "N건 기준"을 제목 옆에 붙인다.
- 표본 10건 미만에 **비율(%)을 쓰지 않는다.** 건수로만 쓴다.
- 제휴카페 수치를 **다이렉트결혼준비와 합산하지 않는다.** 별도 표로 둔다.
- 수집 안 된 카페는 "미수집"으로 적는다. 추정치로 채우지 않는다.
- 백화점 없는 지역(거제·통영·양산 등)은 **매장 비교 대상이 아님을 명시**한다.
